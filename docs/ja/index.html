Windows 版をダウンロード

画面の上端が、ようやく動き出す。

Windows のためのノッチ、Dalu。マウスを乗せると、音楽と歌詞、タイマーが開きます。

Windows 版をダウンロードソースを見る

乗せるだけで、開く。

声に寄り添う歌詞。

Streetlights bloom along the river.

タイミング情報のある曲なら、単語のひとつひとつまで。

ひとつのノッチ、五つのページ。

  • 音楽
  • 集中
  • ファイル棚
  • 予定
  • イヤホン

  1. 一語ずつ、ぴったりと。

    タイミング情報のある曲は、歌うそばから単語が光ります。

  2. ひとつに集中。

    ポモドーロ、タイマーとストップウォッチのラップ、水分、やること。すべてノッチの中に。

  3. 置いて、持ち出す。

    ノッチにファイルを置いて、好きなウィンドウへドラッグ。

  4. 今日を、ひと目で。

    カレンダーのアドレス（.ics）を貼って、リスト・週・月で表示。

  5. ひとタップで静かに。

    何も開かずに、Galaxy Buds のノイズコントロールを切り替え。

ただの黒か、リキッドグラスか。

スクロールすると、2つの見た目を行き来します。

背後の世界を曲げるガラス。

壁紙を選んでください。ノッチが背後の景色を屈折させます。

ドットに乗せると、タブが現れる。

小さなドットに乗せると、タブのアイコンに変わります。それぞれのアイコンの役割はこちら。

タブのアイコン

  • 音楽曲、再生、歌詞
  • 集中ポモドーロ
  • タイマータイマー、ストップウォッチ、ラップ
  • 水分水を飲む時間のお知らせ
  • ファイル棚ファイルをちょっと置く
  • やること時刻を決めて通知
  • 予定リスト・週・月
  • ショートカットよく使うアプリとフォルダー
  • プラグインほかのアプリを操作
  • イヤホンバッテリーとノイズコントロール

隅のアイコン

  • 音量音量とミュート
  • 固定押すとノッチが閉じません

ノッチの位置

閉じているときは細い線だけ。乗せると開きます。

DirectX・OpenGL・Vulkan のゲームが前面にあるあいだ、ノッチは隠れます。

9 バンド、自分だけの音。

イコライザーを整え（スライダーを動かすそばから聞こえます）、片耳だけでもノイズコントロールを保てます。

あなた流に。

Dalu は無料です。

Windows 10（2004 以降）または 11。アカウントも追跡もありません。
