Windows 版をダウンロード

Windows の画面に、ノッチをひとつ。

歌詞、タイマー、ファイル、イヤホンが、マウスを乗せると開きます。

Windows 版をダウンロードソースを見る

ひとつのノッチに、五つのページ

  1. 音楽

    歌詞が単語ごとに流れます

    曲にタイミング情報があれば、単語ごとに合わせて表示します。

  2. 集中

    静かに回るポモドーロ

    ポモドーロ、タイマー、水分記録、やることをひとまとめに。

  3. ファイル棚

    置いて、持ち歩く

    ノッチに置いたファイルは、ほかのウィンドウへドラッグして使えます。

  4. 予定

    カレンダーを月単位で

    カレンダーのアドレス（.ics）を貼ると、リスト・週・月で見られます。

  5. イヤホン

    ノイズコントロールをすぐ切り替え

    Samsung Galaxy Buds のモードをノッチから切り替えます。

背景を屈折させるガラス

壁紙を選んでください。ノッチが背後の景色を屈折させます。

壁紙

ドットに乗せて、タブを選ぶ

小さなドットにマウスを乗せると、タブのアイコンに変わります。

9 バンドのイコライザー

イコライザー、ゲーミングモード、片耳だけでのノイズコントロール。Buds3 Pro でのみ確認しています。

自分で変えられる

100 以上の設定、4 つの言語、プラグインは JSON ファイル 1 つで。

itch.io で無料

Windows 10（2004 以降）または 11。アカウントも追跡もありません。
