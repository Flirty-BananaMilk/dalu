下载 Windows 版

给 Windows 屏幕一个刘海。

歌词、计时器、文件和耳机，鼠标一指就展开。

下载 Windows 版查看源码

一个刘海，五个页面。

  1. 音乐

    歌词逐字滚动

    歌曲带有时间信息时，每个字都踩着节拍出现。

  2. 专注

    安静运行的番茄钟

    番茄钟、计时器、饮水记录和待办事项，集中在一处。

  3. 文件架

    放下文件，随身带走

    拖到刘海上的文件，可以再拖进任何窗口。

  4. 日程

    按月查看日历

    粘贴日历链接（.ics），可按列表、周或月查看。

  5. 耳机

    一键切换降噪

    在刘海上切换三星 Galaxy Buds 的模式。

会折射桌面的玻璃

选一张壁纸，刘海会折射它背后的画面。

壁纸

指一指小圆点，选标签页

鼠标移到小圆点上，它们会变成标签图标。

九段均衡器

均衡器、游戏模式，以及只戴一只耳机也能降噪。仅在 Buds3 Pro 上验证。

为自己而改

上百项设置，四种语言，插件只需一个 JSON 文件。
