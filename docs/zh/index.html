只要歌曲带有时间信息，就能精确到每个字。

五个页面，一个刘海。

  • 音乐
  • 专注
  • 文件架
  • 日程
  • 耳机

  1. 字字踩点。

    歌曲带有时间信息时，每个字随演唱点亮。

  2. 只做一件事。

    番茄钟、计时器与秒表分段记录、饮水和待办，都在刘海里。

  3. 放下，带走。

    把文件停在刘海上，再拖进任何窗口。

  4. 今天，一眼看清。

    粘贴日历链接（.ics），按列表、周或月查看。

  5. 一点，安静。

    不用打开任何东西，就能切换 Galaxy Buds 的降噪。

指向圆点，标签就出现。

指向小圆点，它们就变成标签图标。下面说明每个图标的作用。

标签图标

  • 音乐曲目、播放、歌词
  • 专注番茄钟
  • 计时器计时器、秒表和分段记录
  • 饮水提醒喝水
  • 文件架临时放文件
  • 待办按时间提醒
  • 日程列表、周、月
  • 快捷方式常用应用和文件夹
  • 插件控制其他应用
  • 耳机电量与降噪

角落的图标
